Resolución con Transformada de Laplace — Valores en Tiempo Real
① EDO del Actuador Hidráulico
// Ecuación diferencial del actuador: τ · dPb/dt + Pb(t) = K · Pc(t) // Aplicando L{ } con Pb(0) = 0: τ·[s·Pb(s) − 0] + Pb(s) = K·Pc(s) Pb(s)·(τs + 1) = K·Pc(s) // Función de transferencia: G_act(s) = K / (τs + 1) // Con τ = 0.020s, K = 1.00: G_act(s) = 1.00 / (0.020s + 1) // Polos: s = −1/τ = −50.0
② Respuesta al Escalón (Frenada de emergencia)
// Entrada escalón: L{u(t)} = 1/s Pb(s) = G_act(s) · (1/s) = K / [s(τs+1)] // Fracciones parciales: A/s + B/(τs+1) A = K = 1.00 B = −K·τ = −0.020 // Transformada inversa: Pb(t) = K·(1 − e^(−t/τ)) Pb(t) = 1.00·(1 − e^(−t/0.020)) // Estado estacionario: Pb(∞) = 1.00
③ Lazo de Control PI
// Controlador PI: C(s) = (Kp·s + Ki) / s C(s) = (0.50·s + 0.30) / s // G lazo abierto = C(s)·G_act(s): G_ol(s) = [(0.50·s+0.30)·1.00] / [s·(0.020·s+1)] // Polos L.C.: denominador de T(s)=C·G/(1+C·G) // Estabilidad: todos los polos con Re(s) < 0 ✓ Estado: ESTABLE ✓
④ Deslizamiento λ — Laplace Inversa
// Índice de deslizamiento: λ(t) = (v − r·ω) / v // G rueda (linealizado en λ* = 0.15): G_rueda(s) = −Kω / (s + α) Kω = r/(I·v₀) ≈ 0.012 // Error ABS e(t) = λ* − λ(t): E(s) = Λ*(s) − Λ(s) // Resultado numérico en t actual: λ_ABS = — λ_noABS = — Pb(t) actual = — bar
